AWS Cloud Web Application

Designing and deploying a gardening-products web application using AWS networking, compute, database and object-storage services.

PlatformAmazon Web Services

Project overview

This project involved designing and deploying a cloud-based gardening-products web application on Amazon Web Services. The solution used a custom VPC with public and private subnets, an Amazon EC2 instance to host the Flask application, Amazon RDS MySQL for structured product information, and Amazon S3 for product-image storage. Security groups were used to control HTTP, SSH and database communication between components.

CLOUD ARCHITECTURE & DEVELOPMENT

From network design to deployed web application.

The project connects AWS networking, compute, database and object storage into one working cloud solution.

01

Cloud Architecture

The solution was designed as a multi-tier AWS architecture. Users access the application through HTTP, the EC2 instance runs the web application, RDS MySQL stores product data, and Amazon S3 stores the product images.

02

VPC & Subnet Design

A custom VPC using the 10.0.0.0/16 CIDR range was configured with two public and two private subnets. The public subnets support the web layer, while the private subnets are used for database resources.

03

EC2 Web Server

The Flask application was hosted on an Amazon EC2 Ubuntu instance. Nginx and Gunicorn were used to serve the Python web application through the EC2 web server.

04

RDS MySQL Database

Amazon RDS MySQL stored the structured gardening-product information. The database used a private subnet group so that the database layer was separated from direct public access.

05

Amazon S3 Object Storage

Nine gardening-product JPG images were uploaded to an Amazon S3 bucket. The Flask web application referenced the stored images when generating the final product listing page.

06

Application Development

The application used Python, Flask and PyMySQL to retrieve product records from MySQL and render them through an HTML template. Product images were loaded separately from Amazon S3.

FINAL WEB APPLICATION

Gardening products delivered from the cloud.

The final Flask application retrieves structured product data from RDS MySQL and displays product images stored in Amazon S3.

01

The problem

The project required a web application that could separate structured product data from image storage while remaining accessible through a cloud-hosted environment. The architecture also needed to keep database resources isolated from direct public access and control traffic between the web server, database and internet.

02

The solution

A custom AWS VPC was created with public subnets for the EC2 web server and private subnets for the RDS database. The Flask application ran on an Ubuntu EC2 instance using Nginx and Gunicorn. Product information was stored in RDS MySQL, while nine product images were stored in Amazon S3 and retrieved by the application. Security groups controlled HTTP, SSH and MySQL communication.
